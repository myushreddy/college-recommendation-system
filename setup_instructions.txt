PART A: INSTALL psycopg2 (PostgreSQL adapter for Python)
---------------------------------------------------------

1. OPEN POWERSHELL/TERMINAL IN VS CODE
   - In VS Code, open Terminal (View → Terminal or Ctrl+`)
   - Make sure you're in the project folder

2. INSTALL psycopg2
   Run this command:
   
   pip install psycopg2-binary
   
   Wait for it to complete. You should see "Successfully installed psycopg2-binary"


PART B: CONFIGURE DATABASE PASSWORD
---------------------------------------------------------

3. OPEN database_import.py FILE
   - In VS Code, open the file: database_import.py
   - Look for line 16 (the DB_CONFIG section)

4. UPDATE YOUR PASSWORD
   Find this section:
   
   DB_CONFIG = {
       'host': 'localhost',
       'port': 5432,
       'database': 'college_recommendation',
       'user': 'postgres',
       'password': 'your_password'  # ← CHANGE THIS!
   }
   
   Replace 'your_password' with your actual PostgreSQL password
   (The same password you use to login to pgAdmin 4)

5. SAVE THE FILE
   Press Ctrl+S to save


PART C: RUN THE IMPORT SCRIPT
---------------------------------------------------------

6. RUN THE IMPORT COMMAND
   In the VS Code Terminal (PowerShell), run:
   
   python database_import.py
   
   This will:
   - Connect to the database
   - Import 5,515 colleges
   - Import 5,515 facility records
   - Import 2,786 courses
   - Verify everything imported correctly
